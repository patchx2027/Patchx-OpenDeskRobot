# RK3568 音频实机验证（2026-11-14）

两台 3568A 均运行原厂 Android 11 / Linux 4.19.232。播放使用 `tinyplay` 直连 RK809，格式为 48 kHz、S16_LE、双声道。听感由现场确认。

| 板卡 | 播放条件 | 结果 |
| --- | --- | --- |
| 旧板 | `HP_NO_MIC`，双声道同时播放「乙组，火车飞机」 | 两遍均清楚 |
| 旧板 | `HP_NO_MIC`，左、右分开播放，另一声道的样本全零 | 两轮均清楚，未核对实际发声的喇叭位置 |
| 新板 | `SPK` 播「甲组，苹果香蕉」，`HP_NO_MIC` 播「乙组，火车飞机」 | 现场只听清乙组。原厂 PatchX 运行时也观察到 `HP_NO_MIC`。该路由下的左右独立播放待测 |

测试结束后已关闭播放 PCM、恢复 `Playback Path=OFF` 并删除测试样本。

## Bothlent 麦阵与 H8 接线对照

三块 3568A 均在原厂 Android 上使用校验值相同的 `tinycap` 直采 Bothlent 八路。采集参数为 16 kHz、S16_LE，周期 160 帧、4 个周期，MIC 开启，AGC 关闭。每轮对比 5 秒安静基线和 12 秒同一部手机播放同一段话。现场按相同音量、距离和朝向操作。

| 板卡及接线 | 前四路去直流 RMS（安静 → 播放） |
| --- | --- |
| 旧板，原麦克风及线束 | 28.8 / 29.1 / 18.2 / 17.8 → 27.9 / 28.1 / 17.9 / 17.5 |
| 新板，自带麦阵及线束 | 224.7 / 243.0 / 264.6 / 275.9 → 555.6 / 600.6 / 543.3 / 523.1 |
| 第三块板，旧麦及原 H8 线束，调整接线前 | 63.5 / 63.5 / 34.3 / 31.4 → 55.5 / 55.4 / 31.4 / 28.9 |
| 第三块板，同一套旧麦及线束，调整 H8 插接后 | 32.6 / 32.6 / 33.4 / 29.3 → 264.1 / 205.5 / 184.0 / 193.0 |

现场将旧板的异常定位为接线问题。第三块板调整 H8 插接后，旧麦和原线束在播放时的前四路电平升到安静时的 **5.5–8.1 倍**，并随播放明显起伏。临时录音已删除。

## 旧板 H8 正确接回后的复测

将旧麦和原 H8 线束按正确方向接回旧板后，使用同一部手机按相同距离和音量播放同一段话。两种系统均直采 Bothlent 八路，16 kHz/S16_LE，周期 160 帧、缓冲区 640 帧，MIC 开启、AGC 关闭。每轮安静 5 秒、播放 12 秒。

| 系统与采集工具 | 前四路去直流 RMS（安静 → 播放） | 后四路（安静 → 播放） |
| --- | --- | --- |
| 原厂 Android 11，`tinycap` | 99.3 / 58.0 / 50.6 / 63.4 → 236.1 / 199.6 / 177.5 / 174.5 | 6.4 / 8.1 / 1.0 / 1.0 → 6.4 / 8.1 / 1.0 / 1.0 |
| RAM 启动 Linux 5.10.160-rt89，`arecord`（`hw:0,0`） | 31.7 / 30.3 / 30.2 / 26.3 → 211.5 / 178.0 / 156.9 / 157.1 | 6.4 / 8.3 / 1.0 / 1.0 → 6.4 / 8.2 / 1.0 / 1.0 |

两套系统的前四路均恢复明显声学响应。Android 安静段有瞬时电平升高，两组倍数用于各自的前后对照。测试覆盖原始采集，云端识别另行验收。两套系统的临时录音均删除，采集流关闭，旧板返回原厂 Android。

## 旧板原生 Linux 播放

旧板从 RAM 启动 Linux 5.10.160-rt89（40 MiB 镜像 CRC32 `1d4f9d74`）。原驱动下 SPK 只有呲声，HP_NO_MIC 无声。新版 RK817 模块在 3568A 的 HP_NO_MIC 播放时启用 GPIO148 外部功放，保留驱动原有的停播静音处理。

通过 PatchX `PatchXAudioIO.play_pcm()` 输入 24 kHz、S16_LE 单声道「乙组，火车飞机」，经发布版 ALSA 配置送入 RK809。PatchX 自行选择路由。现场确认听清。

| 时点 | Playback Path | PCM | GPIO148 |
| --- | --- | --- | --- |
| 播放前 | OFF | closed | 高，功放关闭 |
| 播放中 | HP_NO_MIC | RUNNING | 低，功放使能 |
| 播放后 | OFF | closed | 高，功放关闭 |

播放器无错误，PatchX 释放扬声器所有权，探针退出 0。音频单元与集成测试共 23 项通过。验证范围为旧板的本地 PCM 播放，云端全链路和新板原生 Linux 听感待验收。
