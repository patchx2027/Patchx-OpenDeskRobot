# RK3568 原生 Linux 电机板联调

2026 年 11 月 14 日，在 RK3568 上从 RAM 启动 Linux 5.10.160-rt89。内核和基础用户空间沿用已验证的启动镜像，应用目录使用公开分支提交 `085354ac5` 的 PatchX 和 Companion 源码，文件 SHA-256 与发布清单一致。

## 配置串口

这块板的 UART0 硬件地址是 `0xfdd50000`，原生 Linux 设备节点是 `/dev/ttyS0`，调试控制台使用独立的 `ttyFIQ0`。使用同一板级设备树部署时，在本机的 live 配置中将 `patchx.motor_port` 设为 `/dev/ttyS0`。串口使用 115200、8N1。其它板卡先核对 UART 和接线，再填写实际路径。
