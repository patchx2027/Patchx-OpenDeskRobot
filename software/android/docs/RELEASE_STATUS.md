# Android 源码发布状态

## 范围与来源

本次维护入口为 `software/android/`，来自原 Android 仓库提交 `ed91ef7486cdebca00aa32d497f5aa45cb226c0e` 中的 `PatchX-Android-Main-C/`，版本 `1.0.1`。首次导入仅包含清理后的快照，不导入来源仓库的 Git 历史；目标仓库原有提交历史保留。

本发布提供 Java / AIDL 源码、应用资源及构建配置，用于阅读、协作与继续完善。当前不提供完整可构建 APK、Android 系统镜像、Unity 源工程或电机控制器固件。

## 当前可确认的范围

- 维护入口已集中到单一 Android 工程，包名 `com.patchx_main`，版本 `1.0.1`。
- 来源快照的第三方 SDK、原生库、模型和设备授权资源通过 [excluded-inputs.json](excluded-inputs.json) 登记为未分发输入。
